# Good to Great (من جيد إلى عظيم)

كتاب "من جيد إلى عظيم" للكاتب جيم كولينز، منسق للقراءة والمراجعة مع استعراض الصفحات والصور.

## المحتويات:
- `من-جيد-إلى-عظيم.html`: صفحات الكتاب الكاملة بتنسيق ويب تفاعلي.
- `صفحات.html`: استعراض الصفحات بتنسيق ويب.
- `من-جيد-إلى-عظيم-منقح.docx`: النص المنقح بصيغة Word.
- `render-review/`: مراجعة صور وصفحات الكتاب (539 صفحة).
- `image-review/`: صور ورسومات الكتاب.
